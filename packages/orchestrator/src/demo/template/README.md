# Tic-Tac-Toe Arena (Demo Project Scaffold)

A modern, responsive, buildable Tic-Tac-Toe game scaffold built with Vite, vanilla JavaScript, HTML5, and CSS3.

## Features
- **Instant Play**: Runs immediately out of the box in any modern browser.
- **Single-Player Mode**: Play against an AI bot with blocking and winning heuristics.
- **Pass & Play Mode**: Local 2-player multiplayer on the same screen.
- **Scoreboard Tracking**: Preserves round tallies for Player X, Player O, and Ties.
- **Vite Build Setup**: Fast local dev server and optimized production bundling.

## Quickstart

```bash
# Install dependencies
npm install

# Start development server (http://localhost:3000)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
